# jjoapick-detailpage-planner

제품 정보를 한 번 입력하면 **상세페이지 기획**을 자동으로 짜고, 섹션 수를 고르면 **편집 가능한 와이어프레임 캔버스**(가로 860px 세로형)까지 만들어 주는 Claude 스킬입니다. 질문은 3번 이내입니다.

## 설치 (수강생용)

**claude.ai (웹·앱)**
1. [Releases](../../releases)에서 `jjoapick-detailpage-planner.skill` 파일을 내려받습니다. (저장소 전체 ZIP이 아니라 이 파일을 사용하세요.)
2. Claude에서 설정(Settings) → 기능(Capabilities) → Skills로 들어가 파일을 업로드합니다. 코드 실행 기능이 켜져 있어야 합니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.
3. 업로드가 안 되면 파일 확장자를 `.zip`으로 바꿔서 다시 올려 보세요. (내부 형식이 ZIP입니다.)
4. 예전에 설치한 `detailpage-planner`가 있다면 삭제하세요. 두 스킬이 겹쳐서 호출될 수 있습니다.

**Claude Code**
`jjoapick-detailpage-planner/` 폴더를 `~/.claude/skills/` 안에 복사합니다.

**필요한 환경**
- 코드 실행 기능 (파일 생성에 필요)
- 편집 가능한 캔버스(Design 캔버스)를 쓸 수 있는 계정이면 캔버스로 만들어지고, 없으면 글자를 클릭해 수정하는 HTML 파일로 대신 만들어집니다.
- 웹 검색이 켜져 있으면 와디즈 사전 점검에서 최신 안내를 확인합니다.

## 사용법

새 대화에서 "상세페이지 기획해줘"라고 시작하면 됩니다.

| 단계 | 내용 |
|---|---|
| 1 | 제품 정보 입력 (아래 양식) |
| 2 | 방향 확인 + 섹션 수 선택 (8 / 10 / 12 / 15장) |
| 3 | 구성표 확인 (카피가 이미 채워져 있고, 와디즈 스타일 사전 점검 결과 포함) |
| 4 | 와이어프레임 캔버스 생성 |

**입력 양식 (복사해서 사용)**
```
1. 제품·브랜드명 (한글/영문, 슬로건):
2. 한 줄 설명:
3. 스펙·가격 (용량, 사이즈, 옵션, 가격):
4. 꼭 알리고 싶은 특징 3~5개:
5. 누가 사나요? (어떤 사람, 어떤 고민):
6. 분위기 (예: 미니멀, 따뜻한, 고급스러운):
7. 믿을 만한 근거 (판매 순위, 수치, 인증, 특허 등 / 기준 시점과 출처도):
```
모르는 칸은 비워 두거나 "알아서"라고 쓰면 제품 정보로 유추해서 채웁니다.

## 결과물의 특징

- **상세페이지처럼 이어 붙은 한 장**: 가로 860px, 섹션 세로 1200px 이상, 좌우 여백 40px, 글자 82px ~ 22px, 섹션 제목 가운데 정렬
- **제품마다 순서가 달라집니다**: 구매 결정 유형(검증·성능·감성·가격·서비스)과 강점 순위를 분석해 강조할 부분을 앞으로 올립니다.
- **레이아웃은 만들 때마다 무작위로 달라집니다**: 카드 격자, 좌우 교차, 타임라인, 큰 번호 리스트, 원형 사진, 데이터 행 등이 바뀌어 나오고, 항목 개수에 맞춰 배치가 바뀝니다. 시드 번호로 마음에 드는 배치를 다시 만들 수 있습니다.
- **비주얼 섹션**: 연출 이미지 배경 위에 상단 카피(로고·서브·메인 카피)와 하단 픽토그램 바(주요 특징 개수만큼, 선택)
- **이미지 자리는 글자 없는 검은 박스**이고, 어떤 이미지를 넣을지는 구성표에서 알려 줍니다.
- **빈칸 없이 모든 글자를 채웁니다.** 대괄호 자리표시(`[입력]`)가 없습니다.
- **와디즈 스타일 사전 점검**: 만들기 전에 메이커 소개, 배송·교환·환불 안내 같은 필수 섹션을 구성표에 미리 반영합니다.

## 꼭 알아두세요

- 입력하지 않은 수치·순위·인증·가격·보증·후기 같은 사실은 **샘플 값으로 채운 초안**입니다. 샘플로 채운 곳은 보드 옆 주석 스티커의 `샘플 값 교체` 목록에 모여 있으니, 실제 페이지에 쓰기 전에 반드시 실제 값으로 교체하세요. 샘플에는 실존 기관·인증 번호·실명 후기를 쓰지 않습니다.
- 효능·시험 수치·인증 문구는 근거 자료로 직접 확인하세요. 와디즈 점검은 사전 점검용이며 심사 통과를 보장하지 않습니다. 확인하지 못한 항목은 점검 요약에서 그대로 알려 줍니다.
- 연출 이미지는 실제 제품·산지·인물처럼 보이지 않게 "연출 이미지"로 표기하거나 실제 사진을 쓰세요.

```
jjoapick-detailpage-planner/

  references/                 기획 로직, 섹션 구성안, 모듈, 캔버스 규칙, 와디즈 점검표

  scripts/build_wireframe.py  HTML 폴백 생성기
  assets/example-spec*.json   예시 스펙 3종 (가상 제품)
```
