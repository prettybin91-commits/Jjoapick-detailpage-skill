# 상세페이지 해부 (참고 상세페이지 5종 분석)

분석 대상: 고구마말랭이(식품), 유기농 레몬즙 스틱(식품), 산양유 트릿(펫푸드), 생활 안전장갑(생활용품), 보습 로션(화장품). 와이어프레임이 "웹 화면"이 아니라 **이런 상세페이지처럼 보이게** 만드는 규칙이다.

## 1. 공통 구조 (위 → 아래 흐름)

| 순서 | 구간 | 나타나는 모습 |
|---|---|---|
| 1 | 히어로 | 작은 문구 한 줄 + 큰 제목(키워드 강조) + 제품 누끼 + 원형 인증·테스트 배지 2~3개 + 소품 연출 컷 |
| 2 | 신뢰·핵심 요약 | 인증 띠(HACCP 등), 아이콘 4개 라벨 한 줄, 아이콘 카드 3개(아이콘 + 영문 라벨 + 한 줄) |
| 3 | 문제 공감 | 말풍선 속마음 4개, 상황 사진 3컷 + 캡션, 원인 결론 한 줄 |
| 4 | 새로운 관점 | "흔한 생각 → 새로운 생각", 원리 도해 |
| 5 | POINT 01~04 | 번호 라벨 + 제목 + 사진·차트·그리드 + 한두 줄 설명 (포인트마다 비주얼이 다름) |
| 6 | 수치 근거 | 비교 막대 차트, 설문 % 막대 목록, 각주(기준·출처), 인증서·특허 그리드 |
| 7 | 사용법 | 활용·섭취·사용 3~4컷, GIF 자리 |
| 8 | 후기 | 별점 + 후기 제목(인용) + 본문 카드 3~4개 |
| 9 | 선택 이유 | 체크 아이콘 알약 목록 5개, "ZERO" 같은 대형 문구 + 아이콘 3개 |
| 10 | 브랜드 메시지 | 제품·브랜드 이미지 위 약속 문구 |
| 11 | 제품 정보·안내 | 제품 상세 정보 표, 보관·주의 아이콘 행, Q&A, 법적 안내 작은 글씨 |

## 2. 섹션 해부 (모든 섹션이 같은 틀)

`작은 라벨(POINT 01, HOW TO USE, 영문 키워드)` → `제목 1~2줄 (키워드 하나에 강조 박스)` → `서브·본문 1~2줄` → `비주얼 모듈` → `각주(작은 글씨)`

- 제목과 문구는 가운데 정렬, 문장은 짧다.
- 한 섹션에 모듈이 2~4개 들어간다(사진 + 아이콘 목록 + 각주처럼). 텍스트만 있는 섹션은 거의 없다.
- 화면의 절반 이상(약 50~60%)이 이미지다: 제품 누끼, 사용 컷, 사진 그리드, GIF, 도해.

## 3. 배경 리듬

섹션이 **간격 없이 이어 붙고**, 경계는 배경색 교대로 보인다. 흰색 → 연한 톤 → 진한 톤 → 전체 사진이 번갈아 나온다. 구분 장치로 번호 라벨(POINT 01 알약 또는 원형)과 곡선·노치 구분선을 쓴다.
와이어프레임에서는 색 대신 회색 톤으로 표현한다: 흰(#fff) / 연회색(#f1f1f1) / 중간 회색(#dcdcdc) / 진한 회색(#222, 흰 글씨) / 전체 이미지(#111, 흰 글씨).

## 4. 웹 화면과 다른 점 (이것을 피한다)

- 구매 버튼, 입력창, 메뉴, 카드 테두리 격자 같은 **웹 UI 요소가 없다.** 마지막 구매 유도는 가로 띠 배너(검은 바 + 흰 글씨)로 표현한다.
- 섹션 사이에 여백 간격이나 구분 박스를 두지 않는다. 섹션끼리 맞닿는다.
- 박스 테두리와 표 격자를 남발하지 않고, 아이콘·원형 배지·말풍선·알약 같은 **이미지형 모듈**을 쓴다.
- 법적 안내와 출처는 맨 아래, 작은 글씨로 둔다.

## 5. 업종별로 달라지는 점

- 식품: 인증 띠와 원료·무첨가 아이콘이 앞에, 먹는 법·보관법·주의사항이 뒤에 크게 나온다.
- 펫푸드: 문제 공감과 비교 도해, 급여량 표, Q&A가 길다.
- 생활용품: POINT 번호 라벨이 강하고, 특허·인증서 그리드, 제품 도해(말풍선 설명)가 있다.
- 화장품: 고민 공감 말풍선, 성분 라벨 사진, 테스트 결과 차트와 % 막대, 사용 GIF가 핵심이다.

모듈별 만드는 법은 `modules.md`, 장수별 구성은 `page-types.md`.
