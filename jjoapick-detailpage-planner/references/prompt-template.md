# 기획안 프롬프트 템플릿 (사용자가 요청할 때만)

지금까지의 기획을 채워 **하나의 코드블록**으로 출력한다.

```
상세페이지 기획안을 섹션(페이지)별로 만들어줘.

1. 제품 정보
- 제품명: {…}
- 한 줄 설명·스펙·가격: {…}
- 특징: 1. {…} 2. {…} 3. {…} 4. {…}
- 타겟: {…}

2. 기획 방향
- 고객이 바라는 것: {…}
- 구매를 망설이게 하는 이유: {…}
- 불편한 점 / 그때 드는 마음 / 이래선 안 된다: {…} / {…} / {…}
- 이것만 믿으면 사고 싶어지는 한 가지: {한 문장}
- 믿을 만한 근거: 메시지 {…} / 수치·출처 {…}
- 구매 3단계: {…} → {…} → {…}
- 달라지는 모습: {이전} → {이후}
- 구매 유도 띠 배너 문구: {…}
- 톤: 고객이 주인공, 우리는 안내자. 과장·허위 표현, 근거 없는 수치 금지

3. 레이아웃 규칙
- 섹션을 간격 없이 이어 붙인 한 장의 상세페이지, 가로 860px, 세로형(섹션당 1200px 이상), 좌우 여백 40px, 제목 가운데 정렬
- 섹션 틀: 라벨 → 제목(키워드 강조) → 서브·본문 → 비주얼 모듈 → 각주, 배경은 흰/연회색/진한 회색/전체 이미지 교대
- 글자 크기 82px ~ 22px, 수치·출처는 22px
- 이미지 자리는 검은 박스에 "들어갈 이미지" 라벨
- 비주얼 섹션은 전체 배경이 연출 이미지, 정보 섹션은 흰 배경
- 분위기: {…}

4. 카피 규칙
- 메인 2줄 이내, 서브 1줄, 본문 3줄 이내, 서술형 배제, 단어 중심
- 한 섹션에 메시지 하나

5. 섹션별 구성
- P1 ({유형·구분}): {카피 + 구성}
- P2 …

※ 수치·인증·가격은 내가 준 값만 쓰고, 없으면 [실제 … 입력]으로 남겨줘.
```
