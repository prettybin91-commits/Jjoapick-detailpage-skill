# 와디즈 구조와 점검표

STEP 3(와이어프레임을 만들기 전 사전 점검)에서 사용한다. 점검은 구성표와 카피를 대상으로 하고, 구조 보완(Maker, Notice 등)은 구성표에 미리 반영한다.

## 이 문서의 신뢰 범위 (사용자에게도 알린다)
- **확인된 것**
  - 오픈 전에 AI 심사로 프로젝트 문구를 광고 심의 기준과 정책에 맞춰 점검하고, 메이커는 여러 번(보도 기준 최대 5회) 요청할 수 있다. (2025년 10월 보도)
  - 메이커 실물 사진과 소개는 스토리에 필수로 작성하도록 안내된다. (와디즈 메이커센터)
  - AI로 생성한 이미지·콘텐츠가 실제 사용자 경험이나 후기처럼 오인될 수 있으면 수정을 요청한다. 공정거래위원회 추천·보증 표시광고 심사지침 등이 기준이다. (2026년 8월 보도)
  - 메이커 소개와 펀딩 이유를 분명히 담고, 주관적 표현 대신 수치·객관 자료로 전하는 구성이 권장된다.
  - 가로 860px은 제작 현장에서 많이 쓰는 폭이다(공식 규격이라고 단정하지 않는다).
  - 와디즈에는 푸드·산지직송 카테고리가 있고 산지 직송 농산물, 제철 과일·채소 프로젝트도 진행된다. 최근 안내에는 AI 모니터링으로 사전 심사 기간 없이 일정에 맞춰 열 수 있다고 되어 있어, 앞의 "오픈 전 AI 심사 요청" 방식과 다를 수 있다. 현재 절차는 메이커센터로 확인한다.
  - 이미 출시된 제품은 입점 방식을 확인한다. 2023년 1월 시행 정책 기준으로 프리오더 입점은 특별한 혜택(국내 단독, 특별 구성, 한정판)이 요건이다. 오래된 보도에는 다른 채널에 같은 상품이 있으면 리워드형 펀딩이 어렵다는 원칙도 있어 현재 정책은 확인이 필요하다.
  - 식품 프로젝트에서 AI 인물이 제품을 먹은 것처럼 연출한 표현이 수정 요구 대상이 된 사례가 있다. 실제 사용 후기·결과처럼 보이는 AI 연출 이미지는 쓰지 않는다. (2026년 보도)
- **확인하지 못한 것**: 공식 광고 심의 기준 전문, 금지 표현 목록, 이미지 규격 최신 수치 → 메이커센터와 AI 심사로 최종 확인하도록 안내한다.
- 점검표는 사전 점검용이며 심사 통과를 보장하지 않는다.

## 와디즈 권장 흐름 (제작 관행 기준)
오프닝(Hero) → 문제 공감(Pain) → 특징(Trust·Point) → 신뢰 근거(Proof) → **메이커 소개(Maker)** → 사용법(How-to) → 제품 정보·리워드 구성(Info) → 일정·배송·교환·환불·AS(Notice) → 마무리(Brand)

## 입력 방식
와디즈 전용 정보(리워드, 일정, 배송 등)는 **따로 묻지 않는다.** 입력된 정보로 쓰고, 입력되지 않은 항목은 샘플 값으로 채워 `sample` 목록에 올린다. Notice의 배송·교환·환불도 샘플 조건으로 채우고 실제 조건으로 교체하도록 알린다.

## 점검표

| 구분 | 점검 항목 | 확인 방법 |
|---|---|---|
| 구조 | 오프닝, 문제 공감, 제품 소개, 특징, 신뢰 근거, **메이커 실물 사진·소개(필수)**, 리워드 구성, 일정·배송, 교환·환불·AS, FAQ, 마무리가 모두 있는가 | 구성표 대조 |
| 문구 | 주관적 표현이 수치·근거로 바뀌어 있는가 | 카피 검토 |
| 문구 | "최고·최초·유일·1위·역대 최대"에 근거가 있는가 (기준·기간·출처) | 사용자 확인 |
| 문구 | 식품·화장품이면 질병 치료·예방, 의약품 같은 효능 표현이 없는가 | 카피 검토, 불확실하면 메이커센터 확인 |
| 문구 | 인증·시험·특허 표기가 실제 보유 자료와 일치하는가 | 사용자 확인 |
| 문구 | 수치에 집계 기준일과 출처가 표기돼 있는가 | 사용자 확인 |
| 문구 | 이미지 속 글자도 같은 기준으로 점검했는가 | 카피 검토 |
| 신뢰 | 샘플로 채운 후기·수치·조건이 실제 페이지에 그대로 나가지 않도록 교체 목록을 확인했는가 | `sample` 목록 확인 |
| 신뢰 | 시나리오·연출 이미지(특히 AI 생성 인물·사용 장면)가 실제 후기처럼 보이지 않는가 ("연출 이미지" 표기 권장) | 이미지 라벨·문구 검토 |
| 운영 | 펀딩 기간·배송 예정·리워드 수량이 일관되는가 | 사용자 확인 |
| 규격 | 가로폭과 분할 방식이 와디즈 편집기에서 맞는가 | 메이커센터 확인 |
| 심사 | 오픈 전 AI 심사를 돌려 지적 사항을 반영했는가 | 안내 |

상태는 `있음 / 보완 필요 / 해당 없음`. 보완 제안은 사용자의 기존 문구를 바꾸지 말고 **옵션으로 제안**한다.


## 신선 농산물·산지직송 추가 점검 (농산물 제품일 때)

| 구분 | 점검 항목 | 확인 방법 |
|---|---|---|
| 구조 | 생산자·농장 실물 사진과 소개(Maker) — 산지직송에서 특히 중요 | 구성표 대조 |
| 구조 | 수확 시기·발송 일정·교환·환불(신선식품)을 별도 Notice 섹션으로 분리 | 구성표 대조 |
| 문구 | "고당도", "당도 선별", "엄선"에 당도 기준(브릭스)과 측정 방법이 있는가 | 사용자 확인 |
| 문구 | "모두 제거" 같은 단정 표현에 근거와 방법이 있는가 | 사용자 확인 |
| 문구 | 원산지 상세, 품종, 중량·개입 범위, 배송비 포함 여부 표기 | 사용자 확인 |
| 신뢰 | 산지·제품 연출 이미지가 실제 산지·제품처럼 오인되지 않는가 (실제 사진 사용, 연출 표기) | 이미지 라벨 검토 |
| 운영 | 다른 채널에서 이미 판매 중인지, 입점 유형(펀딩·프리오더)과 특별한 혜택 요건 | 메이커센터 확인 |

신선 농산물의 와디즈 전용 서류·심사 기준, 당도 표기 기준, 신선식품 교환·환불 기준은 확인하지 못했으므로 메이커센터 확인으로 안내한다.
