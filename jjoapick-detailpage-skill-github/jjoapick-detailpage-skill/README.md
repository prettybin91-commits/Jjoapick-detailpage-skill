# jjoapick-detailpage-planner

제품 정보를 한 번 입력하면 **상세페이지 기획**을 자동으로 짜고, 섹션 수를 고르면 **편집 가능한 와이어프레임 캔버스**(가로 860px 세로형)까지 만들어 주는 Claude 스킬입니다.

## 설치 (수강생용)

**claude.ai (웹·앱)**
1. [Releases](../../releases)에서 `jjoapick-detailpage-planner.skill` 파일을 내려받습니다. (저장소 전체 ZIP이 아니라 이 파일을 사용하세요.)
2. Claude에서 설정(Settings) → 기능(Capabilities) → Skills로 들어가 파일을 업로드합니다. 코드 실행 기능이 켜져 있어야 합니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.
3. 업로드가 안 되면 파일 확장자를 `.zip`으로 바꿔서 다시 올려 보세요. (내부 형식이 ZIP입니다.)
4. 예전에 설치한 `detailpage-planner`가 있다면 삭제하세요. 두 스킬이 겹쳐서 호출될 수 있습니다.

**Claude Code**
`jjoapick-detailpage-planner/` 폴더를 `~/.claude/skills/` 안에 복사합니다.

## 사용법

새 대화에서 "상세페이지 기획해줘"라고 시작하면 됩니다. 질문은 4번 이내입니다.

| 단계 | 내용 |
|---|---|
| 1 | 제품 정보 입력 (아래 양식) |
| 2 | 방향 확인 + 섹션 수 선택 (8 / 10 / 12 / 15장) |
| 3 | 구성표 확인 (카피가 이미 채워져 있음) |
| 4 | 와이어프레임 캔버스 생성 |
| 5 | 마무리 (와디즈 스타일 점검 / 수정 요청 / 끝) |

**입력 양식 (복사해서 사용)**
```
1. 제품·브랜드명 (한글/영문, 슬로건):
2. 한 줄 설명:
3. 스펙·가격 (용량, 사이즈, 옵션, 가격):
4. 꼭 알리고 싶은 특징 3~5개:
5. 누가 사나요? (어떤 사람, 어떤 고민):
6. 분위기 (예: 미니멀, 따뜻한, 고급스러운):
7. 믿을 만한 근거 (판매 순위, 수치, 인증, 특허 등 / 기준 시점과 출처도):
```

## 결과물 규칙

- 섹션이 간격 없이 이어 붙은 한 장의 상세페이지 (가로 860px, 세로 1200px 이상, 좌우 여백 40px)
- 글자 크기 82px ~ 22px, 섹션 제목 가운데 정렬
- 이미지 자리는 검은 박스, 비주얼 섹션은 배경 전체가 연출 이미지
- 글자를 클릭해 바로 수정 가능

## 꼭 알아두세요

- 수치·순위·인증·가격·보증·후기 같은 **사실 정보는 입력한 것만** 들어가고, 없으면 `[실제 … 입력]` 자리표시로 남습니다.
- 효능·시험 수치·인증 문구는 **근거 자료로 직접 확인**하세요. 와디즈 점검표는 사전 점검용이며 심사 통과를 보장하지 않습니다.
- 편집 가능한 캔버스는 계정에서 해당 기능을 쓸 수 있을 때 만들어지고, 그렇지 않으면 글자를 클릭해 수정하는 HTML 파일로 대신 만들어집니다.
