# 와디즈 구조와 점검표

STEP 5(마무리)에서 사용한다. 와디즈를 언급한 경우 STEP 2·3에서 Maker 섹션을 필수로 넣는 데도 쓴다.

## 이 문서의 신뢰 범위 (사용자에게도 알린다)
- **확인된 것**
  - 오픈 전에 AI 심사로 프로젝트 문구를 광고 심의 기준과 정책에 맞춰 점검하고, 메이커는 여러 번(보도 기준 최대 5회) 요청할 수 있다. (2025년 10월 보도)
  - 메이커 실물 사진과 소개는 스토리에 필수로 작성하도록 안내된다. (와디즈 메이커센터)
  - AI로 생성한 이미지·콘텐츠가 실제 사용자 경험이나 후기처럼 오인될 수 있으면 수정을 요청한다. 공정거래위원회 추천·보증 표시광고 심사지침 등이 기준이다. (2026년 8월 보도)
  - 메이커 소개와 펀딩 이유를 분명히 담고, 주관적 표현 대신 수치·객관 자료로 전하는 구성이 권장된다.
  - 가로 860px은 제작 현장에서 많이 쓰는 폭이다(공식 규격이라고 단정하지 않는다).
- **확인하지 못한 것**: 공식 광고 심의 기준 전문, 금지 표현 목록, 이미지 규격 최신 수치 → 메이커센터와 AI 심사로 최종 확인하도록 안내한다.
- 점검표는 사전 점검용이며 심사 통과를 보장하지 않는다.

## 와디즈 권장 흐름 (제작 관행 기준)
오프닝(Hero) → 문제 공감(Pain) → 특징(Trust·Point) → 신뢰 근거(Proof) → **메이커 소개(Maker)** → 사용법(How-to) → 제품 정보·리워드 구성(Info) → 일정·배송·교환·환불·AS(Notice) → 마무리(Brand)

## 입력 방식
와디즈 전용 정보(리워드, 일정, 배송 등)는 **따로 묻지 않는다.** 입력된 정보로 쓸 수 있는 것만 쓰고 나머지는 `[실제 … 입력]` 자리표시로 남긴다.

## 점검표

| 구분 | 점검 항목 | 확인 방법 |
|---|---|---|
| 구조 | 오프닝, 문제 공감, 제품 소개, 특징, 신뢰 근거, **메이커 실물 사진·소개(필수)**, 리워드 구성, 일정·배송, 교환·환불·AS, FAQ, 마무리가 모두 있는가 | 구성표 대조 |
| 문구 | 주관적 표현이 수치·근거로 바뀌어 있는가 | 카피 검토 |
| 문구 | "최고·최초·유일·1위·역대 최대"에 근거가 있는가 (기준·기간·출처) | 사용자 확인 |
| 문구 | 식품·화장품이면 질병 치료·예방, 의약품 같은 효능 표현이 없는가 | 카피 검토, 불확실하면 메이커센터 확인 |
| 문구 | 인증·시험·특허 표기가 실제 보유 자료와 일치하는가 | 사용자 확인 |
| 문구 | 수치에 집계 기준일과 출처가 표기돼 있는가 | 사용자 확인 |
| 문구 | 이미지 속 글자도 같은 기준으로 점검했는가 | 카피 검토 |
| 신뢰 | 후기·수치를 만들어 넣지 않았는가 | 자리표시 확인 |
| 신뢰 | 시나리오·연출 이미지(특히 AI 생성 인물·사용 장면)가 실제 후기처럼 보이지 않는가 ("연출 이미지" 표기 권장) | 이미지 라벨·문구 검토 |
| 운영 | 펀딩 기간·배송 예정·리워드 수량이 일관되는가 | 사용자 확인 |
| 규격 | 가로폭과 분할 방식이 와디즈 편집기에서 맞는가 | 메이커센터 확인 |
| 심사 | 오픈 전 AI 심사를 돌려 지적 사항을 반영했는가 | 안내 |

상태는 `있음 / 보완 필요 / 해당 없음`. 보완 제안은 사용자의 기존 문구를 바꾸지 말고 **옵션으로 제안**한다.
